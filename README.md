# MMD GameForge

**An independent game creation studio for Unreal Engine, with proprietary AI models trained from scratch and a cloud-first training program.**

MMD GameForge is a Windows-first desktop application for organizing game projects and, over time, designing, building, inspecting, and iteratively improving Unreal Engine games through a dedicated creative workspace.

## Core principles

- **First-party AI:** MMD model weights are initialized and trained from scratch. Pretrained third-party model weights are not the foundation of this product.
- **Cloud-first training:** model training is designed to run on compliant remote notebook/runtime providers; the developer's laptop is not a training dependency.
- **Local desktop, remote compute:** the GameForge desktop app remains a local creative tool; MMD Cloud Training is a separate cloud workflow within the same repository.
- **Unreal-focused:** project workflows, assets, code, scenes, and iteration are designed around Unreal Engine.
- **Human-directed:** users review proposed actions and remain in control of project changes.
- **Honest capability reporting:** planned modules are identified as in development; the application does not claim model inference, cloud orchestration, or Unreal integration before those systems exist.

## Current status

**Phase 02 — Desktop foundation (in progress).**

The repository includes an Electron + TypeScript desktop shell with:
- Dark studio interface and module navigation.
- Dashboard and recent-project list.
- Create a local project workspace after choosing its parent folder.
- Open an existing project directory and inspect a read-only top-level file snapshot.
- Typed, narrow IPC bridge with context isolation and renderer sandboxing.
- Type-checking, automated project-name tests, and Windows/Ubuntu CI workflow.
- Windows x64 NSIS installer generated by GitHub Actions and uploaded as a workflow artifact when CI succeeds.

**MCT-01 — MMD Cloud Training foundation (in progress).**

The initial cloud foundation adds provider-neutral job and checkpoint contracts, a reproducible multilingual pilot configuration, provider policy, security guidance, and contract tests. It does not yet submit cloud jobs, provision GPUs, train a model, or provide a finished cloud dashboard.

World editing, code generation, asset processing, AI inference/training, and Unreal Engine integration remain separate development phases and are not represented as completed features.

## Hardware and research reality

The desktop shell can run on ordinary Windows development hardware. Frontier-scale language, vision, 3D, or audio model training is not realistic on a guaranteed-zero-cost notebook allocation. The model program begins with reproducible small-scale experiments, explicit dataset provenance, evaluation, checkpoint recovery, and measured scaling requirements. Free cloud accelerators are quota-limited and availability is not guaranteed.
