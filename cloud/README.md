# MMD Cloud Training (MCT)

MCT is the cloud-only training subsystem for MMD GameForge.

- MCT-01: provider-neutral job/checkpoint contracts, multilingual pilot config, provider policy and public-repository security rules.
- MCT-02: preflight, from-scratch Transformer trainer, Kaggle/Colab notebooks and resumable checkpoints.
- MCT-03: Dataset Studio, duplicate removal, deterministic document-level splits and provenance reports.
- MCT-04: model profile factory, parameter/memory estimator and SQLite experiment/artifact registry.

See `docs/MCT_04_MODEL_FACTORY.md` for MCT-04 usage. GPU execution remains user-started; free availability is not guaranteed. No pretrained weights, paid fallback, hidden workers or quota evasion.
