# MMD Cloud Training (MCT)

Cloud-only first-party training for MMD GameForge.

- MCT-01: versioned job/checkpoint contracts, multilingual pilot and provider/security policy.
- MCT-02: user-started Kaggle/Colab training runner, random-init Transformer, resumable checkpoints.
- MCT-03: Dataset Studio, normalized deduplication, deterministic document-level splits and provenance.
- MCT-04: model profiles, parameter/memory estimator and SQLite experiment/artifact registry.
- MCT-05: held-out evaluation, optional generation samples, hash-verified portable model bundles.

All first-party weights start from random initialization. No pretrained weights, hosted inference APIs, hidden workers, paid fallback or quota evasion. Free GPU access is provider-controlled and never guaranteed. See the milestone documents under docs/.
